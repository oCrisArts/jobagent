## 📋 OS 8 PASSOS PARA 2 ENTREVISTAS EM 30 DIAS

JobAgent guia o usuário através de um processo testado e comprovado:

### PASSO 1: Destaque Seus 3 Melhores Projetos (STAR Format)
**O que JobAgent faz:**
- Entrevista estruturada: contexto, problema, ação, resultado
- IA ajuda a reescrever com métricas (não inventa, valida)
- Extrai tools, decisões, impacto
- Armazena como "Portfolio Assets"

**Resultado:** 3 highlights que comunicam senioridade

---

### PASSO 2: Foto + Banner (Visual Identity)
**O que JobAgent faz:**
- Analisa foto atual (olhos, luz, confiança)
- Recomenda ajustes (sim, usamos AI/Figma)
- Integra com banner template (Figma)
- Valida: foto profissional ✓, banner presença ✓

**Resultado:** Perfil que parece "mobiliado", não vazio

---

### PASSO 3: Headlines Otimizados para SEO
**O que JobAgent faz:**
```
Input (ruim):
"Product Designer apaixonado por resolver problemas"

Analysis:
❌ Genérico (500k pessoas iguais)
❌ Sem keywords (Product Designer, Figma, SaaS, etc.)
❌ Sem métricas/diferencial

Output (melhor):
"Product Designer | SaaS B2B | AI | Growth | User Research | Figma | +22% Activation Rate"

Por quê?
✓ Keywords para recrutador (SaaS, AI, Growth, Figma)
✓ Métrica real (seniority signal)
✓ Encontrável no LinkedIn search
```

**JobAgent:**
- Analisa seu background
- Extrai 5-7 keywords principais
- Integra 1-2 métricas
- Testa legibilidade + SEO

**Resultado:** Headline que atrai recrutador, não scroll

---

### PASSO 4: About Otimizado (não Autobiografia)
**O que JobAgent faz:**
```
Não é: "Sou designer desde 2015, apaixonado por..."
É: SEO para recrutador

Palavras-chave que recrutador busca:
→ Product Designer
→ Figma, Prototyping
→ AI, Machine Learning integrations
→ User Research, Hotjar
→ Design System
→ Growth, Metrics-driven
→ SaaS
→ B2B Enterprise

O About precisa incluir TODAS essas (natural, não keyword stuffing)
```

**JobAgent:**
- Extrai 15+ keywords do seu histórico
- Reescreve About em formato "encontrável"
- Valida: Recrutador consegue searchear? ✓
- Integra call-to-action (tipo: "aceito convites para...")

**Resultado:** Perfil que aparece em buscas de recrutador

---

### PASSO 5: Experiências com Detalhes Reais
**O que JobAgent faz:**
```
Antes:
"Redesenhei o dashboard"

Depois:
"Redesenhei dashboard de análise usando Figma + user interviews,
reduzindo bounce rate em 18% via Hotjar tracking. Liderou
adoção de novo design system entre 8 times."

Por quê? Comunica senioridade:
✓ Ferramenta específica (Figma)
✓ Metodologia (user research)
✓ Métrica real (18%)
✓ Escala (8 teams)
```

**JobAgent:**
- Por cada experiência: estrutura 5-7 bullet points
- Cada bullet: ferramenta + resultado + escala
- Valida: Métrica é real? Resultado é mensurável?
- Integra com highlights do Passo 1

**Resultado:** Experiências que impressionam recrutador

---

### PASSO 6: 15+ Competências Relevantes por Role
**O que JobAgent faz:**
```
Não é: "Design, UI, UX" (genérico)
É: Keywords que alimentam algoritmo

Competências = visibilidade:
→ Figma, Prototyping, Wireframing
→ User Research, Interviews, Jobs-to-be-Done
→ Design System, Component Architecture
→ Growth, Analytics, Hotjar
→ A/B Testing, Design Thinking
→ Accessibility (WCAG), Design QA
→ AI/ML Integration (ChatGPT, Claude)
→ Pitch, Storytelling
```

**JobAgent:**
- Extrai 20+ competências do histórico
- Prioriza por relevância + mercado demand
- Ordena por frequência (algoritmo LinkedIn recompensa)
- Valida: Competência relacionada à experiência? ✓

**Resultado:** Perfil apareça em 20+ buscas diferentes

---

### PASSO 7: Networking + Atividade (Não ser Passivo)
**O que JobAgent faz:**
```
Aplicou para a vaga?
→ Encontra 3 conexões relevantes na empresa
→ Envia DM personalizada: "Vi a vaga de [role] que vocês
   postaram. Tenho experiência em [keyword]. Aberto a conversar!"
→ Rastreia resposta (automation com templates)

Quer se conectar?
→ Recomenda 5 conexões por dia (recrutadores, hiring managers,
   líderes de produto/design)
→ Valida: Está em companies relevantes? ✓
→ Sugere DM opener otimizado

Content + Engagement:
→ Recomenda posting 1x/semana (tipos: case study, learning, opinion)
→ JobAgent ajuda a escrever (sem ser copypaste)
→ Rastreia: views, engagement, followers growth
```

**JobAgent Networking Intelligence:**
- Mapeia rede ideal (3-5 companies, 2-3 seniority levels)
- Prioriza conexões por relevância
- Automatiza templates + personalizações
- Rastreia ROI (conexões → entrevistas)

**Resultado:** 100-150 conexões novas em 30 dias, networking ativo

---

### PASSO 8: Content = Permanente Visibilidade
**O que JobAgent faz:**
```
Problema: Quem não posta vira currículo
Solução: Postar 1-2x semana (case studies, learnings, insights)

Tipos de Post:
→ Case Study: "Como fiz 18% +Activation em 60 dias"
→ Learning: "3 insights de AI integration em Product Design"
→ Opinion: "Por que matching importa mais que volume"
→ Opportunity: "Procurando Product Designer sênior em SaaS"

JobAgent:
- Ajuda estruturar post (não escreve tudo)
- Reescreve para LinkedIn tone (Casual + Professional)
- Sugere hashtags + timing (quando postar)
- Rastreia: views, comments, followers
```

**Content Calendar:** JobAgent cria roadmap de posts para 90 dias

**Resultado:** Profissional fica CONHECIDO (não invisível)
